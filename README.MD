# ⚖️ LawGuideAI

LawGuideAI is an AI-powered web application that helps users understand legal information through a simple and user-friendly interface. It aims to make basic legal guidance more accessible using Artificial Intelligence.

## 🚀 Features

- 🤖 AI-powered legal assistance
- 📜 Basic legal information
- 💬 Interactive interface
- ⚡ Fast and lightweight
- 🌐 Web-based application

## 🛠️ Tech Stack

- Python
- Flask
- HTML
- CSS
- JavaScript

## 📁 Project Structure

```
LawGuideAI/
│── app.py
│── law_mitra.html
└── README.md
```

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/SiddharthBarkund/-LawGuideAI.git
```

Go to the project folder:

```bash
cd -LawGuideAI
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```
